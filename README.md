# Mosswing Relic Quest

Single-screen pixel adventure for the browser. Move through six compact maps, collect keys, open chests, activate altars, gather relic powers, and defeat the final boss.

## Play

Open `index.html` from a static web server. The game is designed for GitHub Pages and does not need a build step.

## Controls

- `WASD` or arrow keys: move
- `Space`: attack
- `Shift`: dash
- `Q`: switch weapon
- `H`: potion
- `E`: interact
- `M`: music
- `P`: pause

Mobile controls appear automatically in mobile layout.

## Current Features

- Six rebuilt maps: overworld, crypt, sky ruin, lava dungeon, crystal spring, moon citadel
- MP3 BGM loaded from `assets/audio`
- Relic powers: Glow, Echo, Wind, Ember, Prism, Star
- Enemy roles: scout, brute, mage
- Touch controls and fullscreen support for mobile
